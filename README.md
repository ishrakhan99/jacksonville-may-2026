# Jacksonville Weather Analysis

A small data project exploring May weather patterns in Jacksonville, FL using a public weather API.

## What it does
- Pulls daily temperature and rainfall data for Jacksonville from the [Open-Meteo API](https://open-meteo.com/)
- Cleans and structures the data using pandas
- Visualizes temperature highs/lows and daily rainfall using matplotlib

## Why
Jacksonville weather in May has a reputation for being unpredictable. This project pulls real data to actually see those swings instead of guessing.

## Tools used
- Python
- pandas
- matplotlib
- Open-Meteo API (no key required)

## How to run it
Open `jacksonville-may-2026.ipynb` in [Google Colab](https://colab.research.google.com) and run the cells top to bottom.
